# Documentation Index - Todo Swift

Este diretório centraliza a documentação para reimplementacao iOS nativa do projeto `todo_flutter`.

## Ordem recomendada de leitura

1. `ARCHITECTURE.md` - visao geral da arquitetura e limites de camada
2. `14-day-learning-plan.md` - plano pratico dia a dia para aprender iOS refazendo o app
3. `flutter-to-ios-mapping.md` - mapa fiel Flutter -> iOS
4. `flutter-project-analysis.md` - analise funcional e estrutural observada no Flutter
5. `ai-notes.md` - regras obrigatorias/proibidas de implementacao
6. `dependency-injector.md` - como registrar e resolver dependencias
7. `routes-navigation-system.md` - padrao de navegacao
8. `responsive-layout.md` - responsividade para iPhone/iPad
9. `screen-componentization-ai-ready.md` - componentizacao de telas
10. `theme-usage-guide.md` - design tokens e tema

## Escopo funcional esperado

- Splash com guarda de autenticacao
- Login e cadastro
- Home com lista de tarefas
- Criacao, conclusao e exclusao de tarefas
- Persistencia local offline-first
- Sync automatico e manual com backend REST

## Fonte de verdade

Os documentos foram derivados da implementacao real no Flutter em `frontend/todo_flutter/lib` e `frontend/todo_flutter/docs`.
